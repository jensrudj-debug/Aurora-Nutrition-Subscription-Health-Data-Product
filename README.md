# Aurora Nutrition — Subscription Health Data Product

Capstone package proposing Aurora Nutrition's first formally owned data product: **Subscription Health**, serving churn monitoring (Retention), a churn-risk feature set (ML), and a retrieval-augmented retention-support assistant.

## Contents (planned)

1. **Architecture Decision Records** — storage, orchestration, ingestion, agentic AI boundaries, plus a security/privacy/compliance matrix.
2. **Data Product Specification** — consumers, interface contracts, policy-as-code rules, MLOps handoff, LLMOps/RAGOps plan, KPIs, SLAs, cost plan.
3. **Proof Artifact** — working, synthetic-data-based demonstration.

All data in this repository is synthetic. AI-assisted build steps are disclosed in the package.
